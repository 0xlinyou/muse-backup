Muse Backup

Muse Backup is a personal backup tool. Once a day, it backs up the core files of my Muse assistant (SOUL.md, IDENTITY.md, USER.md, MEMORY.md, AGENTS.md and TOOLS.md) into a single snapshot file and uploads it to my own Google Drive folder “Muse 备份”.

It is for my own personal use only. It is not a public service and does not serve other users.

How it works:

  • It reads the six local files and builds one snapshot (muse-new-account-backup-YYYY-MM-DD.md).
  • It uploads the snapshot to my own Google Drive, into the folder “Muse 备份”.
  • It only accesses the backup files it creates in Google Drive (drive.file scope).
